# Google Cloud の準備（OAuth クライアント ID の発行）

このアプリが Google Drive の PDF を読むには、Google に「このアプリを使います」と登録して、
**OAuth クライアント ID** を発行する必要があります。無料で、自分専用ならテストモードのままで使えます（審査は不要）。
所要時間は 10 分ほどです。

## 1. プロジェクトを作る
1. <https://console.cloud.google.com/> を開き、Drive を使っている Google アカウントでログインします。
2. 画面上部のプロジェクト選択 →「新しいプロジェクト」→ 名前は `drive-pdf-reader` など → 作成。

## 2. Google Drive API を有効にする
1. 左メニュー「API とサービス」→「ライブラリ」。
2. 「Google Drive API」を検索して「有効にする」。

## 3. OAuth 同意画面を設定する
1. 「API とサービス」→「OAuth 同意画面」（または「Google Auth Platform」→「ブランディング」）。
2. ユーザーの種類は「外部」。アプリ名は `Drive 書庫`、サポートメールと連絡先メールは自分のアドレス。
3. **テストユーザー**に、自分の Google アカウントのメールアドレスを追加します（必須。追加した人だけがログインできます）。
4. スコープは、画面で追加しなくても動きます（アプリがログイン時に要求します）。追加する場合は次の 2 つです。
   - `https://www.googleapis.com/auth/drive.readonly`（Drive の読み取り専用）
   - `https://www.googleapis.com/auth/drive.appdata`（読書位置の同期用の、アプリ専用の隠しフォルダ）

> テストモードでは、リフレッシュ期間が 7 日で切れることがあり、その場合は再ログインが必要になります。

## 4. クライアント ID を作る
1. 「API とサービス」→「認証情報」→「認証情報を作成」→「OAuth クライアント ID」。
2. アプリケーションの種類は「**ウェブ アプリケーション**」。
3. **承認済みの JavaScript 生成元**に、アプリを配信する URL を追加します（末尾にパスや `/` を付けない）。
   - 開発時: `http://localhost:5173`
   - GitHub Pages: `https://<ユーザー名>.github.io`
4. 「承認済みのリダイレクト URI」は不要です（ポップアップ方式のため）。
5. 作成後に表示される **クライアント ID**（`xxxx.apps.googleusercontent.com`）をコピーします。
   **クライアント シークレットは使いません。**

## 5. アプリに設定する
- アプリのログイン画面の「OAuth クライアント ID」欄に貼り付けます（ブラウザに保存されます）。
- または、ビルド時に `VITE_GOOGLE_CLIENT_ID` として埋め込みます（`.env.local` または GitHub の Actions 変数）。
  クライアント ID は公開されても問題ありません。

## 本棚にするフォルダ
Drive でフォルダを開いたときの URL（`https://drive.google.com/drive/folders/<ID>`）を、ログイン画面の「本棚のフォルダ」に貼ります。
空にすると、マイドライブ直下から始まり、サブフォルダをたどれます。
